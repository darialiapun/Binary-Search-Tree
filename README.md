# Двоичное дерево поиска (BST)

Домашнее задание по алгоритмам и структурам данных: реализация двоичного дерева поиска на Python.

## Что такое BST

Двоичное дерево поиска — это дерево, в котором у каждого узла не больше двух детей и для каждого узла выполняется правило:
все ключи в левом поддереве меньше ключа узла, а все ключи в правом — больше.

```
         50
       /    \
     30      70
    /  \    /  \
  20   40  60   80
```

Благодаря этому правилу поиск, вставка и удаление в сбалансированном дереве работают за O(log n).

## Что реализовано

| Метод | Что делает |
|---|---|
| `insert(key)` | добавляет ключ (дубликаты не добавляются) |
| `search(key)` | возвращает `True`, если ключ есть в дереве |
| `delete(key)` | удаляет ключ, разбирая три случая: нет детей, один ребёнок, два ребёнка |
| `inorder()` | обход «левое → узел → правое», даёт ключи по возрастанию |
| `preorder()` | обход «узел → левое → правое» |
| `postorder()` | обход «левое → правое → узел» |
| `find_min()` / `find_max()` | самый левый / самый правый ключ |
| `height()` | высота дерева (пустое — 0, один узел — 1) |
| `is_balanced()` | `True`, если в каждом узле высоты поддеревьев отличаются не больше чем на 1 |

### Удаление

- **Нет детей** — узел просто убирается.
- **Один ребёнок** — ребёнок встаёт на место удалённого узла.
- **Два ребёнка** — в узел записывается минимум правого поддерева (следующий по величине ключ), а затем этот минимум удаляется из правого поддерева.
